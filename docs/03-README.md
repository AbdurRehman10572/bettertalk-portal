## Usage Rule

1. Discuss or propose a change.
2. Obtain business approval.
3. Update the relevant file.
4. Add the change date and update `07_CURRENT_STATUS.md`.
5. Developers must implement against the latest approved files, not old chat messages.

## Status Labels

- **Approved:** Business decision confirmed.
- **Reported:** Mentioned as present, but not independently tested.
- **To verify:** Requires testing in the live application.
- **Pending decision:** Business owner must decide.
- **Future:** Outside the immediate V1 scope.
