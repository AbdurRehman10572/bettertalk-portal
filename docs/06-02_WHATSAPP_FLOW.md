# Better Talk — WhatsApp Flow (V1)

## 1. Scope and Compliance

- Flow name: **Better Talk Watsapp Auto-Screening**.
- Customer starts the conversation from a WhatsApp CTA/link.
- Use only customer-initiated messaging inside the active 24-hour service window.
- Do not enable business-initiated marketing or utility templates after 24 hours in V1.
- Use simple, human Roman Urdu; use **hum/we** voice.
- Avoid claims such as “therapy/therapist/psychologist” where not appropriate; use “team member,” “counselor,” “support,” and “online session” according to approved copy.

## 2. Approved Opening

> Assalam-o-Alaikum 🌸  
> Better Talk mein khush aamdeed.  
> Aap kis qisam ki support ke liye rabta karna chahtay hain?

## 3. Categories

1. Marriage / Husband-Wife
2. Love / Relationship
3. Breakup / Separation
4. Family / In-Laws
5. Student / Career Issues
6. Depression / Anxiety
7. Parenting / Children
8. Insecurity / Self-esteem
9. Grief / Loss
10. Workplace / Colleagues

Each category must present two approved screening questions. Marriage and Student/Career questions were previously approved; remaining category copy should be treated as content to finalize if the exact wording is not present in the implementation source.

## 4. Gender Preference

Ask which team member the client prefers:

- Female team member
- Male team member
- Koi bhi ho jaye

## 5. Call Consent and Availability

Approved structure:

> Is bare mein hum aapse call par thori baat kar lein. **Kya aap abhi call receive kar sakte hain?**

- 📞 Ji, abhi call kar sakte hain
- 🕐 Abhi possible nahi

If available:

> Hum aapko isi WhatsApp number par call karte hain. **Please phone apne paas rakhein.**

Do not unnecessarily repeat the agent name or promise a female team member in this closing line.

If unavailable, ask for a preferred time for the short initial call. Keep the negative option singular and simple.

## 6. Post-Screening Operational Flow

1. Store category, answers, preference, consent, and preferred time in the portal.
2. Find/create Client ID and create a lead.
3. Assign to an agent.
4. Agent calls to understand the situation; do not state a fixed call duration in client copy.
5. After the call, the agent sends payment details/link in the same WhatsApp chat.
6. Client sends payment proof where required.
7. Agent confirms payment and schedules the final counselor/doctor.
8. Doctor calls the client directly at the scheduled time.

## 7. Meta Ad Path

`Meta ad → WhatsApp chat → category → two questions → gender preference → call consent/time → portal lead → agent initial call → WhatsApp payment link → payment confirmation → doctor appointment → doctor call`

No `wa.me` link is needed after the customer has already initiated WhatsApp through the ad.

## 8. Data to Store

- WhatsApp number and available profile name.
- Ad/campaign/source identifiers where available.
- Category and answers.
- Gender preference.
- Call consent and preferred time.
- Client ID, Lead ID, assigned agent, and timestamps.
- WhatsApp interaction reference where supported.
